**Hyper Text Markup Language**
is a standard markup language for creating web pages, often call it the **skeleton** of a web page, handles sections, margins, titles..., interpreted by the browser with css, js to give the pages that you deal with everyday.

---
**Examples**
- `<!DOCTYPE html>` declaration defines that this document is an HTML5 document.
- `<html>` element is the root element of an HTML page.
- `<head>` element contains meta information about the HTML page
- The `<title>` element spcifies a title for the HTML page(which is shown in the browser's title bar or in the page's tab)
- The `<Body>` element defines the document's body, and is a container for all the visible contents, such as headings , paragraphs, images, hyperlinks, tablers, lists, etc.
- The `<h1>` element defines a large heading.
- The `<p>` element defines a paragraph.
---
## What is an HTML Element?

HTML element is defined by a start tag, content, and an end tab:
_Example_:
```html
<tagname> Content goes here...</tagname>
```

The HTML element is everything from the start of the start to the end of the tag
