## Adress Resolution Protocol

Definition:
**ARP (Address Resolution Protocol)** is a network protocol used to map an IP address to a MAC address inside a local network (LAN).

## Steps

![[ARP1.png]]
1. **D1** Want to send Message to **D2**.
2. He needs the Mac address.
3. **D1** generate an ARP request to get the target MAC. 
![[ARP2.png]]
4. **D2** response with its mac when it receive the request while **D3** ignore it.
